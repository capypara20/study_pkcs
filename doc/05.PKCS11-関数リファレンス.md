# 05. PKCS#11 関数リファレンス（全 ~68 関数 早見表）

公式仕様（OASIS PKCS#11）は英語で量も多く読みにくいので、**全関数を日本語1行で**整理した早見表。
`example_fnList.txt`（SoftHSM2 が公開している関数一覧）と対応している。

凡例（**実装**列）:
- ✅ … `hsm` プログラムで実際に使っている
- △ … cryptoki が内部で自動実行（自分で呼ばない）
- ◯ … cryptoki にラッパーはあるが、このプログラムでは未配線（すぐ足せる）
- ✕ … cryptoki 0.10 に安全ラッパーが無い（生 FFI でのみ可能）

**cryptoki** 列 … `cryptoki` クレートでの対応メソッド。

> まとめ: ✅/△/◯ までが cryptoki で扱える関数。残る ✕ は
> `*Recover` 系・`*OperationState`・複合操作・`GetFunctionStatus`/`CancelFunction`・
> `GetObjectSize`・`CloseAllSessions` のみ（いずれも旧式または特殊用途）。

---

## 命名規則（これだけ覚えれば読める）

PKCS#11 の関数は **すべて `C_` で始まり**、処理系は **3 段ロケット**で命名される。

| 接尾辞 | 意味 | 例 |
|---|---|---|
| `...Init` | 操作の開始。メカニズムと鍵を指定 | `C_SignInit` |
| （無印） | 一発で完了（小さいデータ向け） | `C_Sign` |
| `...Update` | データを少しずつ投入（大きいデータ向け） | `C_SignUpdate` |
| `...Final` | 分割投入の締め。結果を取り出す | `C_SignFinal` |

cryptoki は `Init` + 無印を **1 メソッドに合体**して隠す（例: `C_SignInit`+`C_Sign` → `session.sign()`）。

## C. セッション管理（Session）

| 関数 | 説明 | 実装 | cryptoki |
|---|---|---|---|
| `C_OpenSession` | セッションを開く（RO/RW を選ぶ） | ✅ | `open_rw_session(slot)` / `open_ro_session(slot)` |
| `C_CloseSession` | セッションを閉じる | △ | `Session` の Drop で自動 |
| `C_CloseAllSessions` | あるスロットの全セッションを閉じる | ✕ | ラッパー無し |
| `C_GetSessionInfo` | セッション状態（RO/RW・ログイン有無） | ✅ | `session.get_session_info()` |
| `C_GetOperationState` | 進行中の操作状態を取り出す（退避用） | ✕ | ラッパー無し |
| `C_SetOperationState` | 退避した操作状態を復元 | ✕ | ラッパー無し |
| `C_Login` | PIN でログイン（秘密操作にはほぼ必須） | ✅ | `session.login(UserType::User, Some(&pin))` |
| `C_Logout` | ログアウト | △ | `Session` Drop / `session.logout()` |

> **User と SO**: `C_Login` の種別は 2 つ。**User**=日常の鍵操作、**SO**(Security Officer)=トークン初期化や User PIN 設定など管理用。

## J. 複合操作（Dual-function：性能最適化用）

2 つの処理を1パスでまとめて行う上級者向け関数。通常は使わない。

| 関数 | 説明 | 実装 |
|---|---|---|
| `C_DigestEncryptUpdate` | ハッシュしつつ暗号化 | ✕（ラッパー無し） |
| `C_DecryptDigestUpdate` | 復号しつつハッシュ | ✕（ラッパー無し） |
| `C_SignEncryptUpdate` | 署名しつつ暗号化 | ✕（ラッパー無し） |
| `C_DecryptVerifyUpdate` | 復号しつつ検証 | ✕（ラッパー無し） |

## 残り（◯/✕）を足すなら

- **◯ 未配線**（cryptoki にラッパーあり、`ops/` に関数を足すだけ）:
  `C_CreateObject` / `C_SetAttributeValue` / `C_Encrypt|DecryptUpdate/Final` /
  `C_DigestKey` / `C_WaitForSlotEvent`
- **✕ ラッパー無し**（生 FFI で `src/main.rs` 方式が必要）:
  `C_*Recover*` / `C_Get|SetOperationState` / 複合操作 4 種 /
  `C_GetFunctionStatus` / `C_CancelFunction` / `C_GetObjectSize` / `C_CloseAllSessions`
