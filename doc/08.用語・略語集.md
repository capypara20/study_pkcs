# 08. 用語・略語集（Glossary）

このリポジトリのドキュメント／コードに出てくる略語・用語をまとめた早見表。
「これ何の略？」となったらここを引く。

---

## A. 規格・基盤まわり

| 略語 | 正式 | 読み/意味 |
|---|---|---|
| **HSM** | Hardware Security Module | 鍵を保管し暗号処理を“中で”行う専用ハードウェア |
| **PKCS** | Public-Key Cryptography Standards | RSA 社が作った公開鍵暗号の標準仕様群。#11 はその11番目 |
| **PKCS#11** | — | 暗号デバイスを操作する C 言語 API 標準。別名 Cryptoki |
| **Cryptoki** | Cryptographic Token Interface | PKCS#11 の別名。`cryptoki` クレートの名前の由来 |
| **API** | Application Programming Interface | プログラムから機能を呼ぶための窓口仕様 |
| **FFI** | Foreign Function Interface | 他言語(ここでは C)の関数を Rust から呼ぶ仕組み |
| **ABI** | Application Binary Interface | バイナリレベルの呼び出し規約（構造体の並び順など） |
| **OASIS** | Organization for the Advancement of Structured Information Standards | 現在 PKCS#11 を管理する標準化団体 |

## B. PKCS#11 の構造・認証まわり

| 略語/用語 | 正式 | 意味 |
|---|---|---|
| **Slot** | — | トークンを挿す「差込口」。論理/物理の接続点 |
| **Token** | — | 鍵やデータが入る実体（=金庫）。HSM 本体 |
| **Session** | — | トークンと会話する接続。開く→使う→閉じる |
| **Object** | — | トークン内の中身（鍵・証明書・データ） |
| **Handle** | — | オブジェクトの整理番号。中身そのものではない |
| **Mechanism** | — | アルゴリズム指定（手順）。例 `CKM_RSA_PKCS` |
| **Attribute** | — | オブジェクトに貼るラベル/属性。例 `CKA_SIGN` |
| **PIN** | Personal Identification Number | 暗証番号。ログイン時に入れる |
| **SO** | Security Officer | 管理者ロール。トークン初期化・User PIN 設定担当 |
| **User** | — | 利用者ロール。鍵で署名/暗号などを行う |
| **RO** | Read-Only | 読み取り専用セッション。永続オブジェクトを変更できない |
| **RW** | Read-Write | 読み書きセッション。鍵生成・削除・PIN 管理が可能 |
| **RNG** | Random Number Generator | 乱数生成器（`C_GenerateRandom` が使う） |

### PKCS#11 の定数プレフィックス（`CK*`）

PKCS#11 の識別子は接頭辞で種類が分かる。**CK = Cryptoki**。

| 接頭辞 | 正式 | 例 | 意味 |
|---|---|---|---|
| `C_` | Cryptoki function | `C_Sign` | 関数 |
| `CK_` | Cryptoki type | `CK_ULONG` | 型 |
| `CKR_` | …Return value | `CKR_OK` | 戻り値（エラーコード）。`CKR_OK`=0=成功 |
| `CKO_` | …Object class | `CKO_PRIVATE_KEY` | オブジェクト種別 |
| `CKK_` | …Key type | `CKK_RSA` | 鍵アルゴリズム種別 |
| `CKM_` | …Mechanism | `CKM_AES_CBC` | メカニズム（アルゴリズム） |
| `CKA_` | …Attribute | `CKA_SIGN` | 属性 |
| `CKF_` | …Flag | `CKF_OS_LOCKING_OK` | フラグ（ビット） |
| `CKU_` | …User type | `CKU_SO` | ユーザ種別 |

> `CK_RV` = Cryptoki **R**eturn **V**alue（関数の戻り値型。`0`=`CKR_OK`=成功）。

## C. 暗号アルゴリズム

| 略語 | 正式 | 種別 | 用途 |
|---|---|---|---|
| **RSA** | Rivest–Shamir–Adleman | 非対称 | 署名・暗号 |
| **EC / ECC** | Elliptic Curve (Cryptography) | 非対称 | 短い鍵で強い。署名・鍵共有 |
| **ECDSA** | Elliptic Curve Digital Signature Algorithm | 署名 | EC 鍵での署名 |
| **EdDSA** | Edwards-curve Digital Signature Algorithm | 署名 | Ed25519 等。高速・安全 |
| **Ed25519** | — | 署名鍵 | Edwards 曲線 25519 を使う EdDSA |
| **X25519** | — | 鍵共有鍵 | Montgomery 曲線 25519 を使う ECDH |
| **ECDH** | Elliptic Curve Diffie–Hellman | 鍵共有 | 2者で共有鍵を作る |
| **DH** | Diffie–Hellman | 鍵共有 | ECDH の元になった方式 |
| **AES** | Advanced Encryption Standard | 対称 | 共通鍵暗号の標準 |
| **DES / 3DES** | Data Encryption Standard | 対称 | 旧式の共通鍵暗号（3DES は3重DES） |
| **HMAC** | Hash-based Message Authentication Code | 認証 | 共通鍵＋ハッシュでメッセージ認証 |
| **SHA** | Secure Hash Algorithm | ハッシュ | SHA-256 等。データの要約値を作る |

## D. 暗号モード・パラメータ

| 略語 | 正式 | 意味 |
|---|---|---|
| **IV** | Initialization Vector | 初期化ベクトル。CBC/GCM で毎回変える初期値 |
| **CBC** | Cipher Block Chaining | ブロック暗号の連鎖モード。IV が要る |
| **GCM** | Galois/Counter Mode | 認証付き暗号モード（暗号化＋改ざん検知） |
| **ECB** | Electronic Codebook | 最も単純なモード（弱いので非推奨） |
| **OAEP** | Optimal Asymmetric Encryption Padding | RSA 暗号の安全なパディング方式 |
| **PKCS#1 / PKCS#7** | — | RSA のパディング(#1)、ブロック暗号のパディング(#7) |
| **KDF** | Key Derivation Function | 共有秘密から鍵を導く関数（ECDH の後段など） |
| **KEK** | Key Encryption Key | 鍵を暗号化するための鍵（鍵ラップで使う） |

## E. 鍵のエンコード・データ表現

| 略語 | 正式 | 意味 |
|---|---|---|
| **OID** | Object Identifier | 「1.2.840.10045.3.1.7」のような階層的な識別番号。曲線やアルゴリズムを表す |
| **DER** | Distinguished Encoding Rules | ASN.1 をバイト列に符号化する規則（一意な形式） |
| **ASN.1** | Abstract Syntax Notation One | データ構造を定義する記法。証明書や鍵の標準表現 |
| **PEM** | Privacy-Enhanced Mail | DER を Base64 + ヘッダで囲ったテキスト形式（`-----BEGIN...`） |
| **hex** | hexadecimal | 16進数表記。本ツールはバイト列を hex で入出力する |

---

## F. バージョン・その他

| 略語 | 正式 | 意味 |
|---|---|---|
| **HW** | Hardware | ハードウェアのバージョン等 |
| **FW** | Firmware | ファームウェアのバージョン等 |
| **SoftHSM** | Software HSM | ソフトウェアだけで HSM を模擬する実装（学習・テスト用） |
| **Drop** | (Rust 用語) | 値がスコープを抜ける時に走る後始末。cryptoki はこれで `Finalize`/`CloseSession` を自動化 |
