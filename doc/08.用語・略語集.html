    03
    A · 規格・基盤

    A規格・基盤まわり

    略語正式意味
    HSMHardware Security Module鍵を保管し暗号処理を“中で”行う専用ハードウェア
    PKCSPublic-Key Cryptography StandardsRSA 社が作った公開鍵暗号の標準仕様群。#11 はその11番目
    PKCS#11—暗号デバイスを操作する C 言語 API 標準。別名 Cryptoki。最新は v3.2
    CryptokiCryptographic Token InterfacePKCS#11 の別名。cryptoki クレートの名の由来
    APIApplication Programming Interfaceプログラムから機能を呼ぶための窓口仕様
    FFIForeign Function Interface他言語(C)の関数を Rust から呼ぶ仕組み
    ABIApplication Binary Interfaceバイナリレベルの呼び出し規約（構造体の並び順など）
    OASISOrg. for the Advancement of Structured Information Standards現在 PKCS#11 を管理する標準化団体
    04
    B · 構造・認証

    BPKCS#11 の構造・認証まわり

    Slotトークンを挿す「差込口」。論理/物理の接続点
    Token鍵やデータが入る実体（=金庫）。HSM 本体
    Sessionトークンと会話する接続。開く→使う→閉じる
    Object / Handleトークン内の中身（鍵・証明書） / その整理番号（中身そのものではない）
    Mechanismアルゴリズム指定（手順）。例 CKM_RSA_PKCS
    Attributeオブジェクトに貼るラベル/属性。例 CKA_SIGN
    PINPersonal Identification Number。暗証番号
    SO / User管理者ロール（初期化・PIN設定） / 利用者ロール（署名・暗号）
    RO / RW読み取り専用 / 読み書き（鍵生成・削除・PIN 管理が可能）
    RNGRandom Number Generator。乱数生成器（C_GenerateRandom が使う）
    05
    B · 構造・認証

    PKCS#11 の定数プレフィックス（CK*）

    PKCS#11 の識別子は接頭辞で種類が分かる。CK = Cryptoki。

    接頭辞正式例意味
    C_Cryptoki functionC_Sign関数
    CK_Cryptoki typeCK_ULONG型
    CKR_…Return valueCKR_OK戻り値（エラーコード）。CKR_OK=0=成功
    CKO_…Object classCKO_PRIVATE_KEYオブジェクト種別
    CKK_…Key typeCKK_RSA鍵アルゴリズム種別
    CKM_…MechanismCKM_AES_CBCメカニズム（アルゴリズム）
    CKA_…AttributeCKA_SIGN属性
    CKF_…FlagCKF_OS_LOCKING_OKフラグ（ビット）
    CKU_…User typeCKU_SOユーザ種別

    CK_RV = Cryptoki Return Value（関数の戻り値型。0=CKR_OK=成功）。

    06
    C · アルゴリズム

    C暗号アルゴリズム

    略語正式種別用途
    RSARivest–Shamir–Adleman非対称署名・暗号
    EC / ECCElliptic Curve (Cryptography)非対称短い鍵で強い。署名・鍵共有
    ECDSAElliptic Curve Digital Signature Algorithm署名EC 鍵での署名
    EdDSA / Ed25519Edwards-curve DSA署名高速・安全。Ed25519 は曲線25519版
    X25519 / ECDH— / EC Diffie–Hellman鍵共有2者で共有鍵を作る
    AESAdvanced Encryption Standard対称共通鍵暗号の標準
    DES / 3DESData Encryption Standard対称旧式の共通鍵暗号（3DES は3重DES）
    HMACHash-based Message Auth. Code認証共通鍵＋ハッシュでメッセージ認証
    SHASecure Hash AlgorithmハッシュSHA-256 等。データの要約値を作る
    ML-KEMModule-Lattice KEM (FIPS 203)耐量子(KEM)v3.2 で追加。鍵カプセル化（C_EncapsulateKey 等）
    07
    D · モード

    D暗号モード・パラメータ

    略語正式意味
    IVInitialization Vector初期化ベクトル。CBC/GCM で毎回変える初期値
    CBCCipher Block Chainingブロック暗号の連鎖モード。IV が要る
    GCMGalois/Counter Mode認証付き暗号モード（暗号化＋改ざん検知）
    ECBElectronic Codebook最も単純なモード（弱いので非推奨）
    OAEPOptimal Asymmetric Encryption PaddingRSA 暗号の安全なパディング方式
    PSSProbabilistic Signature SchemeRSA 署名の現代的パディング（推奨）
    PKCS#1 / #7—RSA のパディング(#1)、ブロック暗号のパディング(#7)
    KDFKey Derivation Function共有秘密から鍵を導く関数（ECDH の後段など）
    KEKKey Encryption Key鍵を暗号化するための鍵（鍵ラップで使う）
    08
    E·F

    Eエンコード・データ表現 ／ Fその他

    OIDObject Identifier。「1.2.840.10045.3.1.7」のような階層的な識別番号。曲線やアルゴリズムを表す
    DERDistinguished Encoding Rules。ASN.1 をバイト列に符号化する規則（一意な形式）
    ASN.1Abstract Syntax Notation One。データ構造を定義する記法。証明書や鍵の標準表現
    PEMPrivacy-Enhanced Mail。DER を Base64 + ヘッダで囲ったテキスト形式（-----BEGIN...）
    hexhexadecimal。16進数表記。本ツールはバイト列を hex で入出力する
    HW / FWHardware / Firmware のバージョン等
    SoftHSMソフトウェアだけで HSM を模擬する実装（学習・テスト用）
    Drop(Rust 用語) 値がスコープを抜ける時の後始末。cryptoki はこれで Finalize/CloseSession を自動化
